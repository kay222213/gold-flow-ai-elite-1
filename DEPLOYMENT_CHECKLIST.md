# Gold Flow AI Elite — deployment and activation

## Intended deployment

The recommended deployment is one Render Docker Web Service built from this repository. The image includes both `backend/` and `frontend/`; FastAPI serves the frontend at `/` and the API at `/api/*`, so the phone does not point to `127.0.0.1` and does not need a separately entered API URL. GitHub Pages is optional and only serves the static frontend.

## Render configuration

1. Push the repository to GitHub.
2. In Render, create a Blueprint/Web Service from this repository and use the included `render.yaml` (Docker runtime).
3. Let the first deploy complete without optional feed keys. Then add the provider credentials below in the Render environment dashboard. Secret values belong only in Render, never in source files, Git history or screenshots.
4. Wait for deployment and open `https://YOUR-RENDER-SERVICE.onrender.com/api/health`. It should return JSON even when a particular data provider is not configured; check each provider status before trading.
5. Open the root service URL on your phone. The UI uses the same origin automatically.

## Provider credentials and entitlements
Add these as environment variables in the Render dashboard after the service is created. The Blueprint intentionally omits optional paid-data credentials so the app can boot before those keys are configured; add them in the Render dashboard after the first deployment.

- `TWELVEDATA_API_KEY`: quote/candle feed; provider plan must include the requested gold symbol and intervals. Twelve Data's spot quote is indicative, not your broker's executable bid/ask.
- `FRED_API_KEY`: daily US 10Y yield, real yield and broad trade-weighted dollar context. The trade-weighted dollar series is not the ICE DXY index.
- `TRADING_ECONOMICS_API_KEY`: US economic calendar with event timestamps, impact, actual, forecast, previous and revision data; requires an eligible provider account/plan.
- `OPENAI_API_KEY`: optional AI-assisted macro synthesis using source-backed inputs. Model availability and billing depend on the OpenAI API account. If unavailable, deterministic provider reports still show status but no AI narrative is fabricated.
- `DATABENTO_API_KEY`: licensed CME GC futures trade-level data and, if your subscription grants access, MBP-10 depth. GC futures is a proxy for OTC spot gold, not the whole spot market. Real CVD/footprint/DOM/absorption must not be inferred from a TradingView chart image or normal OHLC candles.
- Broker-independent sizing: if your feed does not provide exact instrument metadata, configure `BROKER_TICK_SIZE`, `BROKER_TICK_VALUE_ACCOUNT_CCY`, `BROKER_VOLUME_MIN`, `BROKER_VOLUME_MAX`, `BROKER_VOLUME_STEP`, and `BROKER_ACCOUNT_CURRENCY` using the exact XAUUSD contract specification for the venue where you manually place the trade. Alternatively enter the complete set in the app's Risk & Calculations tab. Tick value must be account-currency P/L per tick for one full lot. Never guess these values.
- `TRADINGVIEW_WEBHOOK_TOKEN`: generated by Render; paste the same secret into the provided Pine input when creating a TradingView alert. TradingView alerts deliver confirmed candle OHLC and are not a standalone tick feed or order-book feed. A Pine alert needs sufficient live bar history per H4/H1/M15/M5 timeframe to warm up the engine.

## Safety and decision model

- No MT5 login is required for analysis. No broker orders are placed.
- No fabricated price series or fake footprint/CVD data is generated.
- The signal engine requires fresh timestamped candles, aligned H4/H1/M15 context, a completed M5 trigger, liquidity/Fibonacci context, volatility-aware stop, opposing liquidity target, minimum reward:risk, available daily risk budget, and valid sizing specs before a trade-ready candidate can appear.
- The deployed default requires both timestamped trade-level flow and fresh L2 book data, and a recently updated calendar to clear event risk. Missing/stale flow or calendar, calendar blackout, unknown broker sizing, stale quotes/candles or invalid calculations keep the decision gate at NO TRADE or PRICE PLAN.
- A target amount is not a profit guarantee. Daily target is a stop-for-the-day threshold, not an algorithmic promise to reach that amount. The app does not enforce broker-side limits.

## GitHub Pages alternative

The Pages workflow is manual-only and deploys only `frontend/`. To use it, deploy the backend independently and enter that backend's HTTPS origin in **Data & Connections**. Do not enter `localhost` or `127.0.0.1` on a phone. GitHub Pages by itself cannot run the Python backend or store provider secrets.

## Local development

Run `./start_local.sh` on macOS/Linux or `start_local_windows.bat` on Windows. Open `http://127.0.0.1:8000/` for both UI and API. Add provider secrets to `backend/.env` to connect live sources; without credentials, the interface still opens but appropriately shows provider/data unavailable and blocks signals.
